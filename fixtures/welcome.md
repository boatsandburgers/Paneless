# The pleasure of a plain text file

A few words, a little structure, and room to think. **Markdown keeps the important part close:** what you have to say.

This is **Paneless**, a quiet place for your documents. Open a file, settle in, and read. Everything stays on your computer.

## Less between you and the page

Good tools get out of the way. A document should feel like a document, whether it’s a short note or a sprawling technical reference.

> Simplicity boils down to two steps: identify the essential. Eliminate the rest.

Here are a few things you can expect:

- Comfortable typography that feels at home on your system
- A reading column with just enough room to breathe
- Light and dark appearances, ready when you are
  - Or follow your system’s lead
- Code that’s readable from the very first moment

## Small details, considered

Use `⌘O` on macOS or `Ctrl+O` on Windows to open your next file. Adjust the type with the **Aa** button, or find your way with the document outline.

| A little intention | A better experience |
| :--- | :--- |
| Native file access | Your words, without the wait |
| Progressive rendering | Read while the rest arrives |
| A quiet interface | More space for what matters |
| Local by default | No account. No cloud. Just a file. |

### A language of its own

Code deserves a comfortable home, too. Highlighting arrives after your document does, so it never stands between you and the page.

```typescript
interface ReadingRoom {
  light: 'morning' | 'evening';
  distractions: number;
}

const room: ReadingRoom = {
  light: 'morning',
  distractions: 0,
};

function settleIn(document: string) {
  return document.trim();
}
```
